# dev-workflow

Claude Code plugin with the analysis/plan workflow skills:
`setup-workflow`, `analyse-code`, `fix-next-finding`, `fix-all-findings`,
`fix-next-user-finding`, `fix-all-user-findings`, `plan-features`, `pitch-feature`,
`implement-next-feature`, `implement-all-features`, `implement-all-claude-features`.

Run them as `/dev-workflow:<skill>` (or just `/<skill>` when the name is unambiguous).
Start in a project with `/dev-workflow:setup-workflow`.

Install it from the `stames-plugins` marketplace; see the [repo README](../../README.md).
