# User Plan

Running list of features to build and ideas to keep. You write it by hand; Claude adds
entries only with your approval (`/explore-feature`, `/pitch-feature`). Claude builds the
concrete features with `/implement-next-feature` and `/implement-all-features`. Rules (ids,
stamps, deleting done items) are in `list-format.md` of the `dev-workflow` plugin's
`setup-workflow` skill. All paths are relative to `<code root>` unless noted. Items are roughly
ordered by priority inside each section.

Ids: `F<n>` for concrete features (specific enough to build), `I<n>` for ideas: a backlog of
vague ideas that no run touches. `/explore-feature I<n>` works one out with you and turns it
into features. A feature's **Keep open for:** line names ideas its implementation must not
block.

**[HOLD]** after the severity means: don't work on this item until the tag is removed.

Legend: **[H]** most wanted, **[M]** wanted, **[L]** nice to have.
